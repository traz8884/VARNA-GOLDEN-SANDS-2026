# Varna & Nisipurile de Aur 2026

Album foto static, optimizat pentru mobil și desktop.

## Publicare pe GitHub Pages

1. Creează un repository nou pe GitHub, de exemplu `varna-golden-sands-2026`.
2. Încarcă **conținutul acestui folder** în repository (index.html, style.css, script.js și folderul images).
3. Deschide repository-ul > **Settings** > **Pages**.
4. La **Build and deployment**, alege **Deploy from a branch**.
5. Selectează branch-ul `main` și folderul `/(root)`, apoi **Save**.
6. După câteva minute, GitHub va afișa linkul public al site-ului.

Important: dacă repository-ul/site-ul este public, fotografiile sunt accesibile public pe internet.
