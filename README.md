# Varna & Nisipurile de Aur 2026

Album foto static, responsive, pregătit pentru GitHub Pages.

## Publicare
1. Creează un repository public pe GitHub.
2. Încarcă toate fișierele și folderul `images` în rădăcina repository-ului.
3. Settings → Pages → Source: Deploy from a branch.
4. Branch: `main`, folder: `/(root)`, apoi Save.

Pagina principală folosește fotografia `images/1000209387.jpg` ca hero image.
